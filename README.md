# 별빛 큐브

황혼의 오픈월드를 달리는 큐브 파쿠르. 끝없는 언덕 위에 선 일곱 개의 **별의 탑**을 올라 별조각을 모으고, 등대에 불을 밝혀요.

- 몬스터도 전투도 없는 순수 파쿠르. 탑에서 떨어져도 다치지 않지만 다시 올라야 해요.
- 점프는 한 번뿐(더블점프 없음). 공중 대시 한 번과 내려찍기가 있어요.
- 돌기둥 계단 위에 숨은 **별가루**를 찾아보세요.
- 조작: WASD 이동, 스페이스 점프, Shift/오른쪽 클릭 대시, 클릭/J 공중 내려찍기, R 마지막 쉼터로 돌아가기.

```bash
npm install
npm run dev     # 개발 서버
npm test        # 물리·코스·지형 테스트
npm run build   # dist/index.html 한 파일로 빌드
```

Three.js + TypeScript + Vite. 물리는 고정 60Hz 스텝의 직접 만든 엔진이에요.
