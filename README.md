# 별빛 큐브

등대를 출발해 황혼의 일곱 본편 코스와 일곱 원정 코스를 탐험하는 큐브 파쿠르입니다. 본편은 스폰에서 멀어질수록 발판이 좁고 간격이 넓어집니다.

- **초원 돌계단 → 바람의 탑 → 부서진 수로 → 수정 동굴 → 회오리 첨탑 → 잿빛 제련소 → 폭풍의 심장**. 돌길과 색이 다른 빛기둥을 따라 각 코스 입구를 찾으세요.
- 동굴의 낮은 천장을 지나고, 회오리와 제련소에서는 점프 도중 방향을 틀어 벽 끝을 돌아갑니다. 움직이는 발판, 솟구치는 발판, 무너지는 발판도 있습니다.
- 별조각 여섯 개로 폭풍 수호자의 봉인을 풉니다. 충격파를 뛰어넘고 핵이 드러날 때 내려찍으세요. 일곱 번째 별조각을 얻고 등대로 돌아오면 등대가 켜집니다.
- **원정 지도(P)**에서 점멸교, 빙하, 방향 발사대, 스위치 회랑, 회전날 정원, 상승기류 협곡, 대시 관문으로 바로 이동할 수 있습니다. 완주하면 코스별 최고 기록이 브라우저에 저장됩니다.
- **반짝이 코인과 옷장(O)**: 업적, 공중 콤보, 오늘의 의뢰, 별똥 조각으로 코인을 모아 큐브 스킨(액세서리·대시 잔상 색 포함)을 사요.
- **업적(L)**: 누적 통계(이동 거리, 점프, 공중 체류 …)와 숨김 업적을 포함한 25개 업적.
- **공중 콤보**: 땅에 닿지 않고 점프·대시·내려찍기·발사대·발판 착지를 이으면 배율과 등급이 올라가요.
- **오늘의 의뢰**: 날짜로 정해지는 세 가지 의뢰. 모두 끝내면 보너스.
- **별똥별**: 밤이면 근처에 별똥별이 떨어져요. 빛기둥이 사라지기 전에 조각을 주우세요.
- **고스트**: 원정 최고 기록이 반투명 큐브로 함께 달려요.
- **보물 상자 · 정령 도감(G) · 빛구슬 질주(B)**: 코스 밖 들판에도 즐길 거리가 있어요. 숨은 보물 상자 24개(밤엔 빛으로 힌트), 낮밤에 따라 나타나는 정령 12종 수집, 45초 안에 구슬을 모으는 콤보 미니게임.
- **메달과 꼬마별**: 원정 완주에 금·은·동 메달, 별빛 레벨과 칭호, 곁을 따라다니며 밤길을 밝히는 꼬마별.
- **1인칭(V)**: 큐브의 눈높이로 달리는 시점. 위아래로 자유롭게 둘러볼 수 있어요.
- 조작: WASD 이동, 스페이스 점프, Shift/오른쪽 클릭 대시, 클릭/J 공중 내려찍기, R 마지막 쉼터로 돌아가기. 스페이스를 누르는 시간으로 점프 높이를 조절합니다.

```bash
npm install
npm run dev     # 개발 서버
npm test        # 물리·코스·지형 테스트
npm run build   # dist/index.html 한 파일로 빌드
```

Three.js + TypeScript + Vite. 물리는 고정 60Hz 스텝의 직접 만든 엔진이에요.
